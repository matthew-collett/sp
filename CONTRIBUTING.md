# Contributing

Thanks for taking interest in `sp`, all contributions are welcome!

## Setup

```sh
git clone https://github.com/matthew-collett/sp
cd sp
make build
```

You'll need a Spotify developer app to test against — see [Setup](README.md#setup).

## Making changes

Open a branch and PR against `main`. For anything non-trivial, open an issue first so we can agree on direction before you sink time into it.

## Bugs

Open an [issue](https://github.com/matthew-collett/sp/issues) with your OS, `sp version` output, and steps to reproduce.
